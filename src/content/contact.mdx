This body is not rendered. `Header` and `ContactSection` both read the
`contact` frontmatter above; the file's prose exists only as an authoring note.

One object, two render sites — that is what keeps the header's contact row and
the end-of-page call-to-action from drifting apart. `page.tsx` passes the same
`contact.contact` value to both, and `ContactSection.test.tsx` asserts the two
render identical values from a single source.

**The phone number was removed at the redesign.** `requirements.md` Q1 had
confirmed publishing it as plain text, and its Assumptions section recorded
that permanent public visibility was an explicit, informed decision. That
decision was reversed — the field is now optional in the schema and unset
here, so the number appears nowhere on the site.

Note for anyone auditing this: removing it from this file removes it from
`HEAD`, **not from the repository's history**. It was committed to a public
repo and remains readable in earlier commits. Treat it as public.
